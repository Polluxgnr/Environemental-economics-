## 4. Method review

| Item | Assessment |
|---|---|
| Country definition | Atlas masks (Europe) and Atlas user-defined regions (others). Validated on France to 0.004 °C. USA restricted to the contiguous states (documented). |
| Anomalies, seasons, hot season | Correct conventions (DJF with the previous December; hot-season window wraps the year where needed). |
| Noise σ | Detrended, so the trend is not counted as noise. |
| Shock definition | Detrended z-scores, so "hot" does not just mean "recent". |
| Regressions | Two-way FE preferred; wild cluster bootstrap correctly *restricted* (null imposed) with Webb weights and CR1 scaling. |
| Residualised scatter plots | Slopes equal the regression coefficients (FWL with the other climate variable partialled out). |
| Forking paths | All 8 specifications reported. The one borderline result (hot-season GDP, p ≈ 0.04–0.05) is presented as weak. An exploratory split by agricultural exposure (4 clusters) is reported in `REPORT.md` as tried, not as a finding. |
| Causal language | Checked: results are labelled description or correlation; "raises", "causes" and similar wording removed. |

## 5. Known limitations (stated in the paper, not fixable before submission)

- **Few clusters.** 12 countries, so the GDP estimate is imprecise.
- **ERA5 rainfall** is modelled, not gauged; it is weakest before 1979 in data-poor regions.
- **Country averages** are not weighted by exposure (cropland, population).
- **Agriculture share** starts late for Germany, Spain, the USA and Australia.
